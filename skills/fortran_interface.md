# Fortran Interface

Fortran bindings are auto-generated using Shroud.

⚠️ NEVER edit auto-generated files:
- src/umpire/interface/c_fortran/*.f (all Fortran files)
- src/umpire/interface/c_fortran/wrap*.cpp (C wrappers)
- src/umpire/interface/c_fortran/wrap*.h (C headers)
- src/umpire/interface/c_fortran/types*.h (type definitions)
- src/umpire/interface/c_fortran/genc*.inc (generated includes)

To modify Fortran interface:
1. Edit src/umpire/interface/umpire_shroud.yaml
2. Run Shroud to regenerate files (via build system or GitHub workflow)
3. Test generated code compiles
4. Test Fortran examples work

Identifying auto-generated files:
- Look for "Generated by" comments
- Files starting with wrap*, gen*, or types*
- Location: c_fortran/ directory

Shroud configuration (umpire_shroud.yaml):
- Declares C++ classes and functions to wrap
- Specifies naming conventions
- Controls module organization
- Defines type mappings

When adding Fortran support for new features:
- Add declarations to umpire_shroud.yaml
- Regenerate with Shroud
- Add Fortran example in examples/tutorial/fortran/
- Update Fortran tests if needed
- Document Fortran API in comments

Resources:
- Shroud documentation: https://shroud.readthedocs.io/
